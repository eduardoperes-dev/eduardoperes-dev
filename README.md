### ⚓ Sobre Mim

Sou estudante de **Engenharia de Software** focado em **sistemas autônomos de baixa latência, robótica e arquitetura de software distribuída**.

Idealizador e projetista do **Projeto LEVIATHAN** (ODS 4 e 9), um ecossistema de código aberto voltado para a especificação, modelagem e desenvolvimento de uma arquitetura modular de nós para controle de sistemas autônomos.

* 🔭 **Projeto Atual:** `LEVIATHAN-Core-Architecture` — Módulo 1: Especificação de Requisitos de Sistema e Modelagem Arquitetural (C4 Model & UML).
* 🎓 **Formação Atual:** Graduação em Engenharia de Software.
* 🎯 **Foco de Especialização:** Inteligência Artificial aplicada, Robótica e Arquitetura de Sistemas Embarcados/Baixa Latência.
* 🛠️ **Tech Stack & Base:** C++, Python, Modelagem C4, Diagramação UML, Engenharia de Requisitos e Git/GitHub.
